오늘은 클로드 코드와 함께 이 블로그를 처음부터 만들어 봤습니다. 프레임워크 없이 **HTML, CSS, JavaScript** 세 가지만 썼는데, 덕분에 각각이 무슨 일을 하는지 또렷하게 보였습니다.

한 줄로 줄이면 이렇습니다.

> HTML은 **뼈대**, CSS는 **옷**, JavaScript는 **움직임**이다.

## HTML: 페이지의 뼈대

HTML은 화면에 **무엇이 있는지**를 정합니다. 제목, 문단, 버튼, 링크 같은 요소를 배치하는 역할이에요.

```html
<header>
  <a href="#/">나의 블로그</a>
  <button type="button">테마 전환</button>
</header>
<main>
  <h1>나의 블로그</h1>
</main>
```

- `header`, `main`, `footer`처럼 **의미가 담긴 태그**를 쓰면 구조를 읽기 쉽고, 화면 낭독기를 쓰는 사람에게도 도움이 됩니다.
- 이 블로그의 `index.html`은 틀만 있고, 글 내용은 JavaScript가 나중에 채워 넣습니다.

## CSS: 보이는 모습

CSS는 그 요소들이 **어떻게 보이는지**를 정합니다. 색, 글꼴, 여백, 배치가 모두 CSS의 몫입니다.

```css
:root {
  --brand-green: #1a7f37;
}

.page-header--home h1 {
  color: var(--brand-green);
}
```

오늘 특히 유용했던 것들:

- **CSS 변수**: 색을 한곳에 모아 두면 바꾸기 쉽습니다. 첫 화면 제목을 초록색으로 바꿀 때도 변수 하나만 추가했어요.
- **다크 모드**: `prefers-color-scheme`으로 기기 설정을 따르고, 변수 값만 바꿔서 어두운 테마를 만듭니다.
- **반응형**: `@media (min-width: 768px)`처럼 화면 폭에 따라 글자 크기와 여백을 다르게 줍니다. 휴대폰에서도 화면이 옆으로 밀리지 않게 하는 것이 중요했습니다.

## JavaScript: 동작과 변화

JavaScript는 페이지가 **어떻게 움직이는지**를 정합니다. 사용자의 행동에 반응하고, 데이터를 불러와 화면을 바꿉니다.

```javascript
button.addEventListener('click', () => {
  const next = currentTheme() === 'dark' ? 'light' : 'dark';
  document.documentElement.dataset.theme = next;
});
```

이 블로그에서 JavaScript가 하는 일:

1. `posts/` 폴더의 마크다운 파일을 불러옵니다.
2. 마크다운을 HTML로 바꿔 화면에 보여줍니다.
3. 주소(`#/post/...`)에 따라 목록이나 글 화면을 그립니다.
4. 다크 모드 버튼을 누르면 테마를 바꾸고 선택을 기억합니다.

## 셋을 함께 보면

| 기술 | 역할 | 이 블로그에서의 예 |
| --- | --- | --- |
| HTML | 구조 (무엇이 있나) | 헤더, 본문 영역, 테마 버튼 |
| CSS | 표현 (어떻게 보이나) | 색상, 다크 모드, 모바일 화면 |
| JavaScript | 동작 (어떻게 움직이나) | 글 불러오기, 화면 전환, 테마 저장 |

## 그 밖에 알게 된 것

- 마크다운 파일을 `fetch`로 불러오려면 파일을 더블클릭해서 열면 안 되고, **로컬 서버**로 열어야 합니다.
- 글에 들어간 내용을 그대로 HTML로 넣으면 위험할 수 있어서, 특수문자를 먼저 바꿔 두는 **이스케이프** 처리가 필요합니다.

세 가지가 각자 맡은 일을 나눠 갖기 때문에, 하나를 고쳐도 나머지에 영향이 적다는 점이 가장 인상 깊었습니다. 다음에는 글 검색 기능을 붙여 보고 싶습니다.
